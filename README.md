# Quantity mesurement App 
A simple React Native app that converts length, weight, and temperature units. This app allows users to easily convert between various units like meters, kilograms, Celsius, and more.

## Getting Started
Instructions on how to get a copy of the project up and running on your local machine.

### Prerequisites
List any software, libraries, or hardware needed to run this project.
 Lists : 
 - **Node.js (v14.x or above)** : Download from Node.js Official Website.
 - **React Native CLI** : Install it globally using npm
 - **Android Studio / Xcode (for iOS if on macOS)** : Follow the React Native Environment Setup Guide to set up Android/iOS development.




### Installing
Follow these steps to install and set up the project on your local machine.
 - **Clone the Repository** : First, clone the repository to your local machine.
 - **Navigate to the Project Directory** : After cloning, navigate into the project directory:.
 - **Install Dependencies** : Use npm to install the project’s dependencies.
 - **Install Android/iOS Dependencies (Optional)** : For iOS (on macOS), make sure to install the CocoaPods dependencies.
 - **Run the App** : To run the app on an Android emulator or device: <u> npx react-native run-android </u>, To run the app on an iOS simulator (macOS only): <u>npx react-native run-ios </u>.

## Usage
Once the app is running on your emulator or device, follow these steps to start using the app:
- **Open the App** : Launch the app on your device or emulator. You will be presented with a simple interface to convert length, weight, and temperature.
- **Select Measurement Type** :  you can choose between the following categories:

- Length (e.g., meters, kilometers, centimeters)
- Weight (e.g., kilograms, grams, miligrams)
- Temperature (e.g., Celsius, Fahrenheit, Kelvin)

- **Enter the Value to Convert** : For the selected measurement type, enter the value you want to convert (e.g., 10 kilometers).
- **Select Units** : Choose the units you want to convert from and to using dropdowns or pickers:

- Length: Meters, Kilometers, centimeters, etc.
- Weight: Kilograms, Grams, miligrams, etc.
- Temperature: Celsius, Fahrenheit, Kelvin, etc.
- **View Results** : Once you enter a value and select the units, the app will automatically show the converted value in the selected units.
